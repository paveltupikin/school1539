# Школа 1539 · Портал ОГЭ и ЕГЭ

Первая демонстрационная версия для 9–11 классов. ОГЭ и ЕГЭ, четыре предмета, карточки с мгновенной проверкой, короткие пробники и кабинет учителя.

## Запуск

Нужен Python 3.11 или новее. Сторонние пакеты для запуска не требуются.

```sh
python server.py --teacher demo.teacher "Учитель Демо"
python server.py
```

При создании учителя введите демонстрационный пароль длиной от 10 символов. Откройте http://127.0.0.1:8000. Для ученика доступна регистрация в интерфейсе. Учитель создаёт группу и передаёт ученику код вступления. В кабинете учителя можно назначить норму карточек, групповой пробник или персональный пробник со своими вопросами и таймером. Результаты выгружаются в Excel.

Примеры маршрутов: `/oge/math/quiz`, `/ege/russ/test`, `/teacher`, `/account`. Задания ученика и вступление в группу доступны в личном кабинете.

SQLite создаётся рядом с `server.py`. Другой путь можно задать через `PORTAL_DB`. Используйте вымышленные имена. Эта версия рассчитана на локальную проверку сценариев. Перед школьным запуском потребуются настройка хостинга и HTTPS, подтверждение школьных аккаунтов, ограничение попыток входа, резервное копирование и согласование правил обработки данных.

Для математики ОГЭ доступны 13 карточек и пробник на 25 заданий. Пробник — учебная адаптация варианта № 1 из сборника под редакцией И. В. Ященко (2027). № 1–19 проверяются автоматически, № 20–25 доступны для самопроверки по разбору после сдачи. Автоматический результат учитывает только задания с коротким ответом. Для остальных курсов доступно по три демонстрационных задания. На странице ЕГЭ по истории есть ссылка на Historia.

## Банк заданий

Единый источник содержания — `bank/oge-math.json`. В нём задания имеют постоянные идентификаторы. Пробник задаёт порядок полных заданий. Карточка ссылается на задание и при необходимости переопределяет вопрос, ответ и разбор, чтобы проверить отдельный шаг. Общий материал для № 1–5 хранится один раз. Источники указаны в банке. Схемы перерисованы для сайта.

При запуске сервер загружает банк в SQLite и обновляет представления `database_tests` и `database_cards`. Пользовательские данные и сохранённые попытки хранятся в той же SQLite и сохраняются при обновлении каталога. В каждой попытке фиксируются выданные вопросы и ответы для проверки.

После изменения банка обновите версию для GitHub Pages и проверьте, что выгрузка соответствует исходнику.

```sh
python3 question_bank.py
python3 question_bank.py --check
```
