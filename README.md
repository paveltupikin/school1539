# Школа 1539 · Портал ОГЭ и ЕГЭ

Первая демонстрационная версия для 9–11 классов. ОГЭ и ЕГЭ, четыре предмета, карточки с мгновенной проверкой, короткие пробники и кабинет учителя.

## Запуск

Нужен Python 3.11 или новее. Сторонние пакеты для запуска не требуются.

```sh
python server.py --teacher demo.teacher "Учитель Демо"
python server.py
```

При создании учителя введите демонстрационный пароль длиной от 10 символов. Откройте http://127.0.0.1:8000. Для ученика доступна регистрация в интерфейсе. Учитель создаёт группу и передаёт ученику код вступления. В кабинете учителя можно назначить норму карточек, групповой пробник или персональный пробник со своими вопросами и таймером. Результаты выгружаются в Excel.

Примеры маршрутов: `/oge/math/quiz`, `/ege/russ/test`, `/teacher`, `/account`. Задания ученика и вступление в группу доступны в личном кабинете.

SQLite создаётся рядом с `server.py`. Другой путь можно задать через `PORTAL_DB`. Используйте вымышленные имена. Эта версия рассчитана на локальную проверку сценариев. Перед школьным запуском потребуются настройка хостинга и HTTPS, подтверждение школьных аккаунтов, ограничение попыток входа, резервное копирование и согласование правил обработки данных.

Для математики ОГЭ доступны 13 карточек и пробник на 25 заданий. Пробник — учебная адаптация варианта № 1 из сборника под редакцией И. В. Ященко (2027). № 1–19 проверяются автоматически, № 20–25 доступны для самопроверки по разбору после сдачи. Автоматический результат учитывает только задания с коротким ответом. Для русского языка ОГЭ доступны 100 исходных заданий, 280 карточек, 5 учебных пробников № 2–13 и 5 тренировок № 2–9. Для остальных курсов доступно по три демонстрационных задания. На странице ЕГЭ по истории есть ссылка на Historia.

## Банк заданий

Источники содержания — `bank/oge-math.json` и `bank/oge-russ.json`, импортируемые в общий каталог SQLite. Задания имеют постоянные идентификаторы. Пробник задаёт порядок полных заданий. Карточка ссылается на задание и при необходимости переопределяет вопрос, ответ и памятку, чтобы проверить отдельный шаг. Общие условия и тексты хранятся один раз. Источники указаны в банке. Схемы перерисованы для сайта. Поле `public_id` используется в пробнике, карточках и лентах `/oge/math/tasks`, `/oge/russ/tasks`. Сохраняйте его при редактировании задания. Карточка на отдельный шаг получает собственный ID.

При запуске сервер загружает банк в SQLite и обновляет представления `database_tests` и `database_cards`. Пользовательские данные и сохранённые попытки хранятся в той же SQLite и сохраняются при обновлении каталога. В каждой попытке фиксируются выданные вопросы и ответы для проверки.

После изменения банка обновите версию для GitHub Pages и проверьте, что выгрузка соответствует исходнику.

```sh
python3 question_bank.py
python3 question_bank.py --check
```

## Русский язык ОГЭ

PDF «русс огэ27 120 заданий» фактически содержит 100 заданий из подборки РЕШУ ОГЭ № 19223407. Импорт сопоставляет все 100 номеров с PDF; SHA-256 файла и исходные номера сохранены в `provenance`. Условие, авторство текстов и формат задания сохраняются. Скрытые устаревшие требования к сочинению исключены. Ключи содержат допустимые варианты ответов; памятки к правилам написаны для тренировки. Изложения № 1 и аудио в исходнике нет, поэтому работы обозначены как учебные. Сочинения сохраняются для самопроверки и не получают автоматический балл.

В карточках можно выбрать тему, пропустить вопрос, открыть историю и повторить ошибки. В серверной версии повтор ошибок использует последние результаты текущего ученика в SQLite; видимая история последних 100 карточек дополнительно хранится в браузере отдельно для каждого аккаунта. В демоверсии вся история находится на текущем устройстве. Результаты других пользователей недоступны. Источник показывается после сдачи пробника без ссылки на исходную подборку. ID полного задания имеет вид `R-38635`, отдельного шага — `R-38635-1`.

Пять пробников содержат по одному заданию каждого типа 2–13, ещё пять тренировок — по одному заданию типов 2–9. Каждое из 100 исходных заданий входит ровно в одну работу. Учитель по умолчанию назначает первый учебный пробник; персональные вопросы и таймер работают как прежде. Изменение темы и работы не подменяет незавершённую попытку: попытки имеют отдельную область выбора `scope`, добавляемую при миграции без удаления результатов.

Повторный импорт из сохранённой страницы печати с ответами и предоставленного PDF (только для сборки нужны `lxml` и `pypdf`):

```sh
python3 tools/import_russian.py saved-print.html supplied.pdf
python3 question_bank.py
python3 -m unittest discover -s tests -v
node tests/check_frontend.cjs
```
