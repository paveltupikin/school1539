# Школа 1539 · Портал ОГЭ и ЕГЭ

Первая демонстрационная версия для 9–11 классов. ОГЭ и ЕГЭ, четыре предмета, карточки с мгновенной проверкой, короткие пробники и кабинет учителя.

## Запуск

Нужен Python 3.11 или новее. Сторонние пакеты для запуска не требуются.

```sh
python server.py --teacher demo.teacher "Учитель Демо"
python server.py
```

При создании учителя введите демонстрационный пароль длиной от 10 символов. Откройте http://127.0.0.1:8000. Для ученика доступна регистрация в интерфейсе. Учитель создаёт группу и передаёт ученику код вступления. В кабинете учителя можно назначить норму карточек, групповой пробник или персональный пробник со своими вопросами и таймером. Результаты выгружаются в Excel.

Примеры маршрутов: `/oge/math/quiz`, `/ege/russ/test`, `/teacher`, `/progress`.

SQLite создаётся рядом с `server.py`. Другой путь можно задать через `PORTAL_DB`. Используйте вымышленные имена. Эта версия рассчитана на локальную проверку сценариев. Перед школьным запуском потребуются настройка хостинга и HTTPS, подтверждение школьных аккаунтов, ограничение попыток входа, резервное копирование и согласование правил обработки данных.

В каждой паре экзамена и предмета по три демонстрационных задания. Карточки циклически повторяются. Пробники и оценки демонстрируют механику, их форматы и шкалы предстоит согласовать с учителями. На странице ЕГЭ по истории есть ссылка на Historia. Интеграция русского тренажёра ожидает доступа к исходникам.

Общие инструкции для Codex и Claude лежат в [AGENTS.md](AGENTS.md). [CLAUDE.md](CLAUDE.md) импортирует их.
